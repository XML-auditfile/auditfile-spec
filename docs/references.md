# References

Where the files in `sources/` come from. Kept in this repository.
## Belastingdienst (ODB)

Official publications: XSD files, functional specifications (`*_FunHie.pdf`, `*_spec.pdf`), explanations
(`Toelichting*.pdf`), product overviews and validation test service descriptions (`VTS*.pdf`).

- Overview: <https://odb.belastingdienst.nl/auditfiles/>
- All documentation, current and archived: <https://odb.belastingdienst.nl/documentatie/?_sfm_doelgroep=Auditfiles>
- Background XAF 4.0: <https://odb.belastingdienst.nl/auditfiles/achtergrond-informatie-xaf4-0/>
- Website archive (versions no longer on ODB): <https://belastingdienst.sitearchief.nl/?subsite=odbbelastingdienst#archive>

ODB keeps only recent versions online. Folders marked "archive" were downloaded earlier and are no
longer listed.
